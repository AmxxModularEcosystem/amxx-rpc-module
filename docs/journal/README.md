# Журнал разработки

Хронология пройденных этапов AmxxRpc: что сделано, какие решения приняты и **почему**,
что затронуто, что дальше.

## Правила

- **Цель:** преемственность между сессиями — новый агент по журналу должен понять, что и
  почему происходило, и продолжить работу без перечитывания всего ТЗ.
- Один завершённый этап — **одна запись**.
- Имя файла: `NNNN-краткое-имя.md` (сквозная нумерация, без пропусков).
- Запись **самодостаточна по контексту**, но **не дублирует** требования/дизайн — ссылается
  на файлы и ID (`docs/08-open-questions.md`, `FR-…`, `AR-…`, `docs/design/10` §…).
- Структура записи:
  - **Дата · Этап · Статус**
  - **Контекст** — зачем этап, из чего исходили
  - **Сделано**
  - **Решения и обоснование** (со ссылками на требования/дизайн)
  - **Открытые нити**
  - **Затронутые артефакты**
  - **Дальше**
- После добавления записи — обновить индекс ниже.
